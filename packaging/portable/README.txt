NATIVE HUB {version} - portable build (Windows 10/11, 64-bit)

1. Unzip this folder anywhere (a USB drive works).
2. Open "NATIVE HUB.exe". Nothing needs to be installed.

Because this folder contains a file named "portable", everything is kept
next to the executable:
  data\   database, downloads and WebView profile
  Games\  installed games (you can change it in Settings)
Delete the "portable" file to use the normal Windows folders instead
(%APPDATA%\dev.nativehub.app, %LOCALAPPDATA%\dev.nativehub.app and
Documents\NATIVE HUB). The optional GitHub token is stored in the Windows
Credential Manager of the current user.

Requires Microsoft Edge WebView2, which ships with Windows 11 and most updated
Windows 10 PCs: https://developer.microsoft.com/microsoft-edge/webview2/

The executable is not signed: if SmartScreen warns you, click "More info" >
"Run anyway".

The interface is in English by default; switch to Spanish in Settings.
NATIVE HUB tells you when a new version is published; in this portable build
you download the new ZIP yourself.

NATIVE HUB does not include or download ROMs, ISOs, BIOS, firmware or keys.
