NATIVE HUB 1.0: the catalog now stays fresh on its own from GitHub, with search and filters, a guided first run, clear errors with a copyable log, adapters tested on popular games and the new N icon.

## What's new

- **Catalog served from GitHub.** The app checks the published catalog (every 6 or 24 hours, or by hand in Settings) and imports it only when it is newer and passes validation. No app update needed to get new projects.
- **Search and filters.** Search and Discover share one browser: filter by type, console, family and status, hide inactive projects and sort by relevance, name, last update, newest or stars. Filters are remembered while the app is open.
- **Guided first run.** A short welcome sets the language, theme, games folder and automatic checks. You can open it again from Settings.
- **Clear errors and a copyable log.** Errors say what failed and what to try. Settings › Log copies the recent log (with your user folder hidden) or opens its folder, ready to attach to a bug report.
- **Adapters tested.** Every adapter is downloaded and installed from the project's official release in CI on Windows. The game page shows what was tested, on which version and when. Nine adapters: 2 Ship 2 Harkinian, Ship of Harkinian, SpaghettiKart, Starship, Zelda 64: Recompiled, Unleashed Recompiled, sm64coopdx, DevilutionX and gen1recomp.
- **New icon.** The executable, installer and taskbar use the N logo.
- **MIT license.** NATIVE HUB's code is MIT. The catalog data keeps its CC BY-SA 4.0 license.

## Known limits

- Windows 10/11 x64 only. Linux and macOS are planned for 1.x.
- The installer and the .exe are not code-signed, so SmartScreen may warn on first launch.
- Adapter tests cover download and installation. Playing with real game files is checked by hand and marked separately on the game page.
