NATIVE HUB 1.1: ZIP downloads now install on their own, and when an .exe can't be downloaded the app gets the ZIP of the same release instead.

## What's new

- **ZIP downloads install on their own.** When a ZIP finishes downloading (its SHA-256 already checked), NATIVE HUB extracts it into your games folder straight away and then deletes the ZIP. If extraction fails (damaged file, unsafe path, folder not empty), the ZIP stays and "Install…" is still there, with the error shown.
- **Falls back to the ZIP.** If an .exe or installer can't be downloaded (antivirus, broken link, checksum mismatch), the Windows ZIP of the same official release is downloaded instead.
- **Same safety.** Extraction still rejects paths outside the game folder, symbolic links and oversized archives. Installers and portable .exe files are never deleted, and nothing runs until you press "Launch".

## Known limits

- A ZIP whose name doesn't say it is for Windows (for example `game.zip`) isn't picked as the fallback.
- Updates of installed games keep their own flow with backups; their ZIP is not deleted yet.
- The installer and the .exe are not code-signed, so SmartScreen may warn on first launch.

## Novedades (español)

- **Los ZIP se instalan solos**: al terminar la descarga se descomprimen en tu carpeta de juegos y después se borran. Si algo falla, el ZIP se queda y puedes reintentar con «Instalar…».
- **Si el .exe no se puede descargar**, se baja el ZIP de Windows de la misma versión oficial.
- **La misma seguridad**: sin rutas fuera de la carpeta del juego, sin enlaces simbólicos, y nada se ejecuta hasta que pulses «Ejecutar».
